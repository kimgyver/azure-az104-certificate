모든 포트
모든 프로토콜

You are creating a metric alert rule for an Azure virtual machine. You add two conditions to the alert rule: Percentage CPU greater than 90 percent AND Available Memory Bytes less than 1 GB. When does the alert fire?
이거 틀린 답이야?
When both conditions have been true at any point within the evaluation period

짧게 말하면 👉 그 답은 틀렸어.

좋은 포인트 짚었어 👍
결론부터 말하면:

👉 “각 조건이 evaluation period 내 ‘어느 시점이든 한 번이라도 만족하면 된다”
이걸 만들려면 기본 AND 조건만으로는 안 되고, aggregation + window 설정을 활용해야 해.

✔️ 왜 기본 설정으로는 안 되냐

기본 Metric Alert:

AND 조건 = 같은 시점(same time slice) 에 둘 다 true여야 함

그래서 네가 말한 것처럼:

“evaluation period 안에서 각각 한 번이라도 true”

👉 ❌ 기본 AND로는 구현 불가

✔️ 해결 방법 (핵심 아이디어)

👉 각 조건을 “순간값”이 아니라
👉 “evaluation window 동안 조건이 한 번이라도 발생했는지” 로 바꿔야 함

✔️ 설정 방법
방법 1: Aggregation 활용 (가장 현실적인 방법)

각 metric 조건을 이렇게 바꿔:

1️⃣ CPU 조건
Metric: Percentage CPU
Aggregation: Max
Condition: > 90
Window: 예) 5분

👉 의미:

“지난 5분 동안 CPU가 90%를 넘은 적이 한 번이라도 있으면 true”

2️⃣ Memory 조건
Metric: Available Memory Bytes
Aggregation: Min
Condition: < 1GB
Window: 동일하게 5분

👉 의미:

“지난 5분 동안 메모리가 1GB 아래로 떨어진 적이 한 번이라도 있으면 true”

✔️ 이렇게 하면 결과
CPU spike (10:01) → Max 조건 만족
Memory drop (10:04) → Min 조건 만족

👉 같은 시점 아니어도
👉 같은 evaluation window 안이면

✅ 둘 다 true → alert 발생

✔️ 핵심 구조

👉 Aggregation + Window = “within evaluation period” 효과

✔️ 한 줄 정리

👉

기본 AND → “동시에 true”
Aggregation(Max/Min) 사용 → “기간 내 한 번이라도 true”
✔️ 인터뷰용 한마디

“To achieve ‘within evaluation period’ behavior, we use aggregations like Max or Min over the evaluation window, so each condition reflects whether the threshold was breached at any point during that period.”

원하면
👉 
evaluation frequency vs window size 차이 (시험 단골)
👉 
alert noise 줄이는 방법 (실무 중요)

이것도 이어서 정리해줄게.

✔️ 1. Crash-consistent backup

👉 “디스크 상태만 그대로 찍는 가장 기본 수준”

👉 “컴퓨터 전원 갑자기 꺼진 상태”

장점
빠름
오버헤드 거의 없음
단점
앱 깨질 수 있음
DB 복구 필요 가능
✔️ 2. File-consistent backup

👉 “파일 시스템 레벨까지 정리된 상태”

특징

open file / cache 정리
file system consistency 보장
비유

👉 “모든 파일 저장하고 정상 종료한 상태”

장점
파일 손상 거의 없음
OS 레벨 안전
단점
application transaction consistency 없음
✔️ 3. Application-consistent backup ⭐ (가장 중요)

memory state 정리
application quiescing 수행

👉 “DB backup + 서비스 정상 종료 상태”

장점
