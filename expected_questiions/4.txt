💡 핵심 개념: Application Gateway Path-based Routing

Azure Application Gateway는 path rules를 평가할 때:

More specific paths must be matched before general paths

Reorder the path rules so that /* is listed last in the URL path map
Explanation
For both v1 and v2 SKUs, path rules are processed in the order they are listed in the portal. The wildcard path /* is matching all requests first because it is at the top of the list. Moving /* to the end ensures that more specific paths like /api/* and /images/* are evaluated first, and only unmatched requests fall through to the default. Reference: https://learn.microsoft.com/en-us/azure/application-gateway/url-route-overview

맞아, 이 문제의 핵심은 **“path rule은 priority 숫자가 아니라 ‘목록 순서’로 평가된다”**는 점이야.
